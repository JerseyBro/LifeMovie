# Design Direction V0.1

LifeMovie should feel like a quiet product that understands time and memory, not an AI tool.

## Direction

Warm Minimalism + Editorial + Light Cinematic

## Principles

- Photos First
- Content First
- Time First
- AI Invisible
- Simplified Chinese First

## Avoid

- AI purple gradients
- glowing AI orb
- robot / magic branding
- tech dashboard blue
- statistics-heavy home screen
- complex tab shell

## Typography

Use system fonts. Chinese titles should be clear and calm; body copy should be readable. Avoid excessive font weights and custom font files in this sprint.
