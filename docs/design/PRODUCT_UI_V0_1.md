# Product UI V0.1

Sprint 0.8 upgrades the app from engineering demo toward usable Chinese product prototype.

## Screens

- Onboarding: “发现相册里那些你已经忘记的故事”
- Photo Permission: explains local photo use; Limited Library is a valid state.
- Indexing: shows real indexed count, not fake AI progress.
- Discovery Feed: editorial story feed with hero photo, title, time range/metadata and CTA.
- Memory Detail: hero media, date range, representative media, timeline, count and coarse location hint.
- Person Timeline: represented through year sections when injected/mock person ids exist.
- Memory Lab Debug: debug-only technical tuning surface.

## Formal UI terminology

Use: 记忆, 故事, 发现, 这些年, 这段旅程, 照片, 视频, 时间, 地点.

Avoid in formal UI: MemoryCandidate, MemoryRule, Ranking, Score, Signal, MediaIndex, Pipeline.
